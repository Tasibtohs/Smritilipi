# স্মৃতিলিপি (Smritilipi) — নোট ও ডায়েরি অ্যাপ

[![Platform](https://img.shields.io/badge/Platform-Android-green.svg)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-2.0.0-blue.svg)](https://kotlinlang.org)
[![Compose](https://img.shields.io/badge/Jetpack%20Compose-M3-purple.svg)](https://developer.android.com/jetpack/compose)
[![Database](https://img.shields.io/badge/Room-Database-orange.svg)](https://developer.android.com/training/data-storage/room)
[![Version](https://img.shields.io/badge/Version-V1.0.1-brightgreen.svg)]()

**স্মৃতিলিপি (Smritilipi)** হলো অ্যান্ড্রয়েডের জন্য তৈরি একটি আধুনিক, নিরাপদ ও নান্দনিক নোট ও ব্যক্তিগত ডায়েরি লেখার ১০০% অফলাইন অ্যাপ্লিকেশন। চমৎকার ২০+ বাংলা ফন্ট, ১৬+ কালার থিম ও কাস্টম কালার প্যালেট, পিন নোট, গোপন নোট (পাসওয়ার্ড প্রটেকশন), ফোল্ডার/গ্রুপ ব্যবস্থাপনা, বুকলেট স্টাইল ল্যান্ডস্কেপ পিডিএফ এক্সপোর্ট, দৈনিক অনুস্মারক এবং সম্পূর্ণ অফলাইন ব্যাকআপ ও রিস্টোর ফিচার এতে অন্তর্ভুক্ত রয়েছে।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. 📝 **আধুনিক ও মসৃণ নোট এডিটর:**
   - রিয়েল-টাইম অটো সেভ ও লাইভ ওয়ার্ড/লাইন কাউন্টার।
   - ফন্ট সাইজ, লাইন স্পেসিং, টেক্সট কালার, ব্যাকগ্রাউন্ড কালার ও টেক্সট অ্যালাইনমেন্ট কাস্টমাইজেশন।
   - বোল্ড, ইটালিক, আন্ডারলাইন ও স্ট্রাইকথ্রু ফরম্যাটিং সুবিধা।

2. 🖋️ **২০+ প্রিমিয়াম বাংলা ফন্ট সাপোর্ট:**
   - অনুপম মাহদী, আলিনুর এফোর্ট, আলিনুর গোধূলি, আলিনুর ইচ্ছামতী, আত্মা, বাঁধন জননী, বাসন্তী, কল্পনা, কবিতা, শহীদ তাহমিদ তামিম, মাহফুজ এ. কে., মাহফুজ বনলতা, মাহফুজ বর্ণমালা, মাহফুজ চিরকুট, মোহিনী, ওরিন, রূপসী বাংলা, শকুন্তলা, শরীফা ফিফা, এবং সবুজ নলুয়া।

3. 🎨 **১৬+ প্রিমিয়াম গ্লাসমরফিজম থিম ও কাস্টম থিম বিল্ডার:**
   - সোনালি ক্লাসিক (Royal Gold), রাজকীয় বেগুনি (Royal Purple), নীল সমুদ্র (Ocean Blue), প্রকৃতি সবুজ (Nature Green), গোধূলি গোলাপি, মিনিমাল মনোক্রোম, ইত্যাদি।
   - ডার্ক ও লাইট মোড টগল এবং মনমতো কাস্টম কালার প্যালেট তৈরির সুযোগ।

4. 📂 **গ্রুপ ও ক্যাটাগরি ব্যবস্থাপনা:**
   - ব্যক্তিগত, সাহিত্য, কাজ, আইডিয়া ইত্যাদি নানা গ্রুপ তৈরি ও নোট বিন্যাস।

5. 🔒 **গোপন নোট ও পাসওয়ার্ড নিরাপত্তা (Hidden Notes):**
   - সংবেদনশীল নোটগুলোকে ৪ সংখ্যার সুরক্ষিত পিন/পাসওয়ার্ড দিয়ে নিরাপদে সংরক্ষণ করার সুবিধা।

6. 🗑️ **রিসাইকেল বিন ও ট্র্যাশ রিকভারি:**
   - অসাবধানতাবশত মুছে ফেলা নোট নিরাপদে ট্র্যাশে সংরক্ষিত থাকে এবং যেকোনো সময় পুনরুদ্ধার করা যায়।

7. 🖨️ **প্রফেশনাল ল্যান্ডস্কেপ বুকলেট PDF এক্সপোর্ট:**
   - একক নোট কিংবা নির্বাচিত/সমস্ত নোট নিয়ে ২-কলামের শৈল্পিক ল্যান্ডস্কেপ ম্যাগাজিন ও বই স্টাইল PDF তৈরি ও প্রিন্ট।
   - বাংলা নামসংখ্যার সূচিপত্র ও কাভার পেজ সহ জেনারেশন।

8. 💾 **১০০% অফলাইন ব্যাকআপ ও রিস্টোর:**
   - ডিভাইসের স্টোরেজে JSON ফাইল হিসেবে ব্যাকআপ সংরক্ষণ ও রিস্টোর করার পূর্ণ স্বাধীনতা।

9. ⏰ **দৈনিক লিখন অনুস্মারক (Daily Reminder):**
   - প্রতিদিন নির্দিষ্ট সময়ে লেখার অনুপ্রেরণা জাগাতে অ্যালার্ম ও নোটিফিকেশন সিস্টেম।

## 🛠 টেকনোলজি স্ট্যাক (Tech Stack)

| কম্পোনেন্ট | প্রযুক্তি |
|---|---|
| **Language** | Kotlin 100% |
| **UI Framework** | Jetpack Compose (Material Design 3) |
| **Architecture** | MVVM (Model-View-ViewModel) + Clean Architecture |
| **Database** | Room ORM (SQLite Engine with Migration Support) |
| **Concurrency** | Kotlin Coroutines & StateFlow / SharedFlow |
| **Preferences** | Jetpack DataStore / SharedPreferences Repository |
| **PDF Engine** | Android PrintFramework & Canvas Rendering (Landscape A4) |
| **Alarms & Receivers** | Exact AlarmManager & BootReceiver |

## 🚀 বিল্ড ও রান করার নিয়ম (Building & Running)

### পূর্বশর্ত (Prerequisites):
- Android Studio Ladybug (বা যেকোনো আধুনিক সংস্করণ)
- JDK 17+
- Android SDK (API Level 24 থেকে API 36+)

### কমান্ড লাইন থেকে বিল্ড:
```bash
# Debug APK বিল্ড করতে
gradle assembleDebug

# টেস্ট রান করতে
gradle :app:testDebugUnitTest
```
